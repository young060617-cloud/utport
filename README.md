# UT Port — 언더테일 팬게임 모바일 포팅 앱

PC용 GameMaker 팬게임(data.win)을 가져와 모바일용 구조로 변환하고, 첨부한 레이아웃의 가상패드로 실행하는 안드로이드 앱 프로젝트입니다.

## 빌드
1. Android Studio에서 이 폴더를 엽니다 (Gradle 동기화).
2. 기기 연결 후 Run, 또는 `./gradlew assembleDebug`.

## 사용법
- "게임 폴더 가져오기": data.win이 있는 폴더 선택 (사운드 ogg 등 함께 복사)
- "ZIP / data.win 가져오기": zip 또는 단일 파일
- 변환 규칙: `data.win → game.droid`, 파일명 소문자·평탄화, `.exe/.dll` 제외
- 목록에서 탭하면 실행, 길게 누르면 삭제

## 가상패드 (VirtualPadView.kt)
| 위치 | 버튼 | 키 |
|---|---|---|
| 좌상단 | 주사위(회색) / R / 주사위(청록) | ESC / R / F4 |
| 좌하단 | ← → | 방향키 좌/우 |
| 우상단 | C, Z, X | C / Z / X |
| 우하단 | ↑ ↓ | 방향키 상/하 |

멀티터치 지원. 주사위 버튼의 키는 원본 앱에서 확인되지 않아 임의로 ESC/F4로 지정했으니 `buttons` 목록에서 바꾸세요.

## 중요: 아직 연결되지 않은 부분
GameMaker 러너(실제로 게임을 구동하는 엔진)는 YoYo Games 소유라 포함하지 않았습니다.
`GameRunner.attach()`가 연결 지점이며, 현재는 변환 성공 안내 화면만 표시합니다.
러너를 연결해야 실제 게임이 실행됩니다. 빌드는 이 환경에서 검증하지 못했습니다.
